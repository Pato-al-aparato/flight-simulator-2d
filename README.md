# Flight Simulator 2D

Simulador espacial 2D desarrollado como proyecto final de DAM. El objetivo es construir una simulación visual sencilla pero consistente, combinando física simplificada, control manual y automático e instrumentación de vuelo.

## Estado

**En desarrollo.** Actualmente el proyecto se encuentra en fase de diseño y definición de la arquitectura inicial.

## Objetivos principales

- Simular el movimiento de una nave en 2D.
- Aplicar gravedad dependiente de la altitud.
- Incorporar progresivamente velocidad, resistencia atmosférica y consumo de combustible.
- Permitir control manual real de la nave.
- Añadir un modo de piloto automático.
- Representar el vuelo mediante una interfaz JavaFX inspirada en instrumentación de vuelo.
- Completar una misión de lanzamiento, entrada en órbita simplificada y aterrizaje.

## Tecnologías previstas

- Java
- JavaFX
- CSS
- Git y GitHub

## Enfoque

El proyecto busca mantener un equilibrio entre tres áreas:

- **Física:** suficientemente coherente para que la simulación tenga sentido, sin intentar reproducir un modelo aeroespacial real.
- **Control:** interacción manual de la nave y automatización mediante piloto automático.
- **Interfaz:** HUD e instrumentación visual integrados con una representación 2D del vuelo.
